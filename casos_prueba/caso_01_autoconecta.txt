DOCUMENTO DE DISEÑO (RESUMEN) - AutoConecta
Squad: Crédito Vehicular · Salida prevista: marzo 2027

1. Objetivo
Dar a los clientes con crédito vehicular un módulo en la app de Banca Móvil para ver dónde está su auto, agendar mantenimiento en talleres afiliados y recibir devoluciones cuando se cancela un servicio del taller.

2. Funcionalidades
- Ver la ubicación actual del vehículo y el historial de ubicaciones de los últimos meses.
- Agendar, reprogramar y cancelar citas de mantenimiento en talleres afiliados.
- Devoluciones: si el taller cancela un servicio ya pagado, el monto se abona en la cuenta del cliente.

3. Arquitectura
- App Banca Móvil (módulo nuevo) -> API Gateway del banco -> microservicios en AWS (vehículos, citas y devoluciones) con base de datos PostgreSQL en AWS.
- Dentro del clúster los microservicios se llaman entre sí por la red interna.
- La versión piloto de la API de vehículos (v1, 2025) sigue activa para la app anterior hasta que migren todos los usuarios.

4. Integraciones
- Proveedor de GPS: instala el equipo en cada auto y nos envía las posiciones cada 2 minutos por webhook.
- Talleres afiliados: al agendar una cita les enviamos los datos del cliente (nombre, DNI, celular y placa) para que lo atiendan. Cada taller entra a un portal de citas con un usuario y una clave que comparte su personal.
- Core bancario: las devoluciones se abonan con el servicio de abonos del core, usando una cuenta de servicio de AutoConecta.
- El área de Cobranzas pidió acceso al historial de ubicaciones para encontrar vehículos de clientes con cuotas atrasadas.

5. Autenticación
Los clientes ingresan con el login de Banca Móvil (IAM del banco).

6. Monitoreo
Logs de aplicación en CloudWatch.

7. Pendientes
- Definir cuánto tiempo guardamos las posiciones del GPS.
- Definir con Cobranzas el alcance de su acceso.
